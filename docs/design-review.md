# 배포 전 디자인 비교 (2026-09-07)

Figma의 개발자 확인 페이지에서 약관 동의(300:5209), iOS 로그인(300:1546), 설정(487:8129)을 비교했다. 전체 앱 모든 상태의 검토를 완료했다는 뜻은 아니다.

## 수정

- 약관 제목 자체로 문서를 열고 체크박스만 동의 상태를 바꾸는 develop 동작을 유지했다. 별도 보기 버튼은 없다.
- 약관 제목의 밑줄을 제거하고 15px에서 시안의 16px Medium으로 맞췄다.
- 약관 체크박스의 오른쪽 정렬과 48px 행 간격을 복원했다. 48px 터치 영역과 작은 화면 스크롤을 유지한다.
- 전체 동의 위 간격을 28px로 보정했다.
- 공통 비활성 버튼 배경을 시안의 gray400 (#C4C4C4)으로 맞췄다.
- 설정 버전 표시 위 여백을 60px로 맞췄다.

## 기능 요구로 유지한 차이

- 개인정보 항목은 실제 동의 범위를 나타내는 ‘개인정보 수집·이용 동의’ 문구를 유지한다.
- 설정의 문의하기는 요청받아 추가한 기능이다. 서비스 이용약관 열람 메뉴도 유지한다.
- 연결할 공지 URL이 없는 상태에서는 빈 공지 메뉴를 노출하지 않는다.
- 버전은 고정된 MVP 문구 대신 설치된 앱의 실제 버전을 표시한다.
- 로그인은 시안의 로고, 버튼 위치·크기·간격·색상 기준을 유지하며 시스템 인증창은 iOS가 표시한다.

## 확인

약관과 설정을 360×780 기준으로 Flutter 렌더링하여 비교했다. 렌더링 이미지는 build/design-review/에 있다. 시스템 상태 표시줄은 기기 안전 영역을 따른다. 작은 화면의 스크롤과 약관 열람 시 동의가 변경되지 않는 동작은 기존 위젯 테스트로 검증한다.
