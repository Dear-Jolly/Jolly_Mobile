# 약관 문서 연결

2026-09-07, Dear Jolly → 관련링크의 기존 빈 페이지 세 개에 초안을 작성했다.
문서들은 기존에 Notion Sites에 게시된 페이지이며, 앱에는 로그인용 notion.so 주소 대신 공개 주소를 사용한다.

| 문서 | 공개 주소 | 연결 화면 |
| --- | --- | --- |
| 서비스 이용약관 동의 | https://yeonjeen-0821.notion.site/service-agree | 가입 약관 |
| 개인정보 수집·이용 동의 및 처리방침 | https://yeonjeen-0821.notion.site/privacy | 가입 약관, 설정 |
| 마케팅 정보 수신 동의 | https://yeonjeen-0821.notion.site/marketing | 가입 약관 |

밑줄 친 제목은 문서를 열고 오른쪽 체크박스는 동의 상태를 변경한다.
앱 내 브라우저를 우선 사용하고 열기 실패 시 외부 브라우저로 재시도한다.
공개 주소는 `lib/core/config/legal_documents.dart`에서 관리한다.

## 정식 시행 전 확정할 내용

현재 문서는 검토용 초안이다. 운영자 사실 확인 없이 정식 동의 문서로 시행하지 않는다.

- 법적 운영자명, 개인정보 보호책임자, 시행일, 가입 가능 연령
- 소셜 로그인 제공 항목, 서버 로그·자동 수집 정보와 목적별 처리 근거
- AI 업체·호스팅 수탁자, 전송 항목, 국외 이전 근거·국가·보유기간·거부 방법, AI 학습 이용 여부
- 계정·편지·백업·동의 이력의 실제 보관기간과 파기 방식
- 마케팅 채널·항목·선택 수집 이용 동의, 철회 절차 및 서버 반영

문의 이메일은 기존 ‘문의 메일’ 페이지에서 확인한 주소를 반영했다.
서버의 동의 이력 기록·철회·별도 국외 이전 동의는 이번 모바일 링크 연결만으로 구현되지 않는다.
